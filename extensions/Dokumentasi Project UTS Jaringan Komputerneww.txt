1. Pendahuluan

Project ini membangun sebuah topologi jaringan di Cisco Packet Tracer yang terdiri dari 3router (Router2, Router3, Router4), 4 switch (Switch0 sampai Switch3), dan 10 PC (PC0sampai PC9). Setiap router memakai network yang berbeda, dan salah satu networkdibagi menjadi 3 VLAN. Konektivitas antar network dibuat dengan dua cara: static routingdan dynamic routing menggunakan RIP versi 2.

1.1 Tujuan

Menentukan alamat IP pada setiap perangkat, dengan network berbeda untuk tiaprouter.


Mengonfigurasi 3 VLAN pada salah satu network.


Mengonfigurasi static routing pada 3 router.


Mengonfigurasi dynamic routing RIP pada 3 router (pada salinan file Packet Tracer).


Menguji konektivitas dan mendokumentasikan hasilnya.

8. Analisis

Dengan static routing, setiap route harus dimasukkan manual, sehingga jika topologiberubah administrator perlu mengubah konfigurasi di setiap router.


Dengan RIP, route dipelajari otomatis lewat pertukaran informasi antar router,
sehingga konfigurasi lebih ringkas dan menyesuaikan perubahan topologi.


Pada tabel routing, route static ditandai kode S dan route RIP ditandai kode R.





VLAN memisahkan broadcast domain pada Switch0, dan komunikasi antar VLANdapat berjalan karena Router2 memakai subinterface (router-on-a-stick).




9. Kesimpulan

Topologi dengan 3 router dan 4 switch berhasil dikonfigurasi dengan pengalamatan IPyang berbeda untuk tiap router, 3 VLAN pada network Router2, serta routingmenggunakan static route dan RIP versi 2. Seluruh PC dapat saling berkomunikasi antarnetwork setelah routing dikonfigurasi (isi sesuai hasil pengujian sebenarnya).
